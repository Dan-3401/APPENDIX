## 掲載方針

説明文と案内は日本語です。日本語の企画書は語句・文法を校正し、添付画像と中国語原稿は原文のまま掲載しています。中国語の企画書は参考原本として併載しています。企画書のHTML版は全文閲覧用にレイアウトを調整したものです。

『神聖刻痕 Root』の中国語手書き原稿は、方向補正済みの製本版PDF全15ページを掲載しています。ページごとの閲覧とPDF原本の表示に対応しています。

[TXT版の索引](補足資料・出典一覧.txt) · [ファイル対応表](manifest.json)

## 更新について

GitHub Pages は `main` ブランチのルートを公開します。HTMLと添付ファイルを更新して同ブランチに反映すると、閲覧ページも更新されます。
手書き原稿の更新時は `manuscripts/` に画像を配置し、`index.html` の原稿欄、TXT索引、`manifest.json` の対応情報を更新してください。
