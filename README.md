## 掲載方針

説明文と案内は日本語です。添付画像および既存の中日両言語のDOCXは提供時の内容を維持しています。中国語の企画書は参考原本として併載しています。企画書のHTML版は全文閲覧用にレイアウトを調整したものです。

『神聖刻痕 Root』の中国語手書き原稿は現在整理中です。準備が整い次第、同じ公開ページに追加します。

[TXT版の索引](補足資料・出典一覧.txt) · [ファイル対応表](manifest.json)

## 更新について

GitHub Pages は `main` ブランチのルートを公開します。HTMLと添付ファイルを更新して同ブランチに反映すると、閲覧ページも更新されます。
手書き原稿の追加時は `manuscripts/` に画像を配置し、`index.html` の原稿欄、TXT索引、`manifest.json` の対応情報を更新してください。
